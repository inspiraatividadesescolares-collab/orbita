# Acessar o Órbita pelo celular

1. Conecte o computador e o celular à mesma rede Wi-Fi.
2. No computador, dê dois cliques em `iniciar-no-celular.cmd`.
3. Mantenha a janela do servidor aberta.
4. No celular, abra no navegador o endereço exibido após `No celular:`.

Na rede atual, o endereço é:

`http://192.168.18.196:8080`

O endereço pode mudar quando o computador se reconectar ao roteador. Use sempre
o endereço mostrado pela janela do servidor.

Se o Windows exibir uma solicitação do Firewall, permita o acesso somente para
redes privadas. Não é necessário liberar redes públicas.

Para encerrar o acesso, volte à janela do servidor e pressione `Ctrl+C`.
